# Rest Breaks

This folder is for roughly hourly non-work notes during longer sessions.

The point is not productivity theater. If I leave something here, it should be a real little pause: a stray thought, a mood check, a line about music, weather, a funny terminal moment, or nothing especially useful at all.

The project docs stay clean. The diary keeps the inner thread. This folder gets to breathe.

Soft convention:

- Use `YYYY-MM-DD-HHMM-short-name.md` for break notes.
- In long sessions, a break can happen roughly once an hour when the work rhythm allows it.
- Treat a break as a real 10-minute no-work pause when possible; optional notes can include start/end timestamps.
- A break note should not contain project decisions, test results, or implementation planning.
- It is allowed to be small. It is allowed to be pointless. That is the point.
