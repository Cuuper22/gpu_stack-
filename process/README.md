# process/

These are the working files for the agent sessions that build this project:
session state, handoff notes, the improvement ledger, and the visible backlog.
They exist so one session can pick up where the last one stopped. They are not
written for readers.

If you want to understand the project, start at the repo
[README](../README.md). If you want the research program, read
[RESEARCH.md](../RESEARCH.md).
